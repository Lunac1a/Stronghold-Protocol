# 五名干员接入版

范围：望、赤刃明霄陈、丰川祥子、维什戴尔仅三技能；凯尔希·思衡托仅二技能。其他技能暂停验收。沿用项目特效与自动释放策略，没有手动关闭技能。基于原项目提交 `54cdad26021452791d7921277e099f72ae646299`。

## 本轮修正

- 望主棋子及四枚跟子统一使用真实棋子Spine模型；移除白色地板占位，触发伤害、占位失效及场景退出时清理模型。维什戴尔三技能攻击动画改为每次攻击播放一次，结束回到技能待机，实测Begin/Idle/Loop切换及非循环攻击片段通过。

- 望三技能改为技力满自动开，避免敌人在棋子范围内、普通攻击范围外时不再开技能。每次开启补8枚棋子，溢出按原规则部署；库存下完自动结束，剩余弹药返还，有费用和库存且冷却结束会在已选位置继续下。
- 五名干员均改为满潜能、满信赖。普通仍为精二1级/技能4级，精锐仍为精二60级/技能7级；培养、模组、价格、份数沿用项目规则。改动在构建器中维护，重新生成不会丢失。未修改原项目干员的潜能与信赖设定。
- 维什戴尔采用用户提供时序：主伤害后4帧残影爆炸，8帧余震，精锐模组12帧第二次余震；多目标同帧依次结算，双角色交叉引爆顺序有专项测试。残影保留，同一次攻击成功引爆后去重，下一次攻击可再次引爆。
- 用户提供的望字幕JSON与陈测评DOCX作为机制解析资料核对，数值以官方数据缓存为准。测评满级专三的数值不会直接覆盖项目培养等级。本项目不模拟技能手动提前关闭。

## 运行

安装Node.js 22或更高版本。解压源码，将“卫戍协议完整游戏素材.zip”合并到源码根目录，保留public/assets目录结构。完整素材包已包含五名新干员及原项目素材，不需要另外合并美术包与敌人补充素材包。在源码目录运行 `npm install`，已合并完整素材包时不需要额外下载素材；只使用单独美术包时需运行 `npm run setup` 获取原项目基础素材；之后运行 `npm start`，进入 http://localhost:3000 。验收场景为 http://localhost:3000/dev/custom-battle.html （自定义 PORT 时使用对应端口）。

普通游戏从首页进入，新增角色在普通商店抽取，三张合成精锐。验收场景的固定高血量敌人与首次免费技能仅用于快速查看；后续按实际规则自动战斗。

复现：`npm run test:custom`、`npm run verify:custom`、`npm run verify:preview`。服务使用其他端口时设 `SP_URL`；四浏览器工具为 `node tools/verify-custom-multiplayer.mjs`，精锐设置 `SP_FORM=elite`。
